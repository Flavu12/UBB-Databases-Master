
# PLAY — More Than a Word

## Project Overview

PLAY is a responsive and interactive website created for the Adaptive Web Design course.

The website explores the English word "play" through its definitions, origins, derived forms, different contexts, and personal interpretations.

The main goal is to show that play is more than just a game. It can represent creativity, music, sports, performance, technology, imagination, and connections between people.

The website also includes interactive activities that allow visitors to experience play instead of only reading about it.

## Technologies Used

The project was developed using:

- HTML5 — page structure and content
- CSS3 — styling, layout, and responsive design
- JavaScript — interactive elements and games

No external frameworks or libraries are required.

## Website Sections

### 1. Home

The homepage introduces the word PLAY with the message "More than a word."

It uses a large title, a pink and purple gradient, and decorative elements to create a visually engaging introduction.

The "Press to explore" button takes visitors to the next section.

### 2. Discover — Decode the Word

This section presents the meaning and history of the word PLAY.

It includes:

- Different meanings of play as a verb and noun
- The Old English origins of the word
- Derived and related words, such as playful, player, replay, playback, gameplay, and playground

Information about definitions and etymology is based on Cambridge Dictionary and the Online Etymology Dictionary.

### 3. Many Worlds

This interactive section demonstrates how the meaning of PLAY changes in different contexts.

Visitors can choose between five categories:

- Gaming — play as exploration and problem-solving
- Music — play as artistic expression
- Sports — play as teamwork and competition
- Theatre — play as acting and performance
- Technology — play as starting digital media

Each category displays a different illustration featuring an astronaut, together with a title and description.

JavaScript dynamically updates the displayed image and text when a category is selected.

### 4. Perspectives

This section explores personal and literary interpretations of play.

It includes my personal perspective, where I describe play as a way to reconnect with my inner child, enjoy simple moments, create memories, and bring family and friends closer together.

The section also presents two quotations attributed to:

- Roald Dahl
- William Shakespeare

These literary quotations provide additional perspectives on the meaning of play. They are not presented as responses from people interviewed for this project.

### 5. Playground

The Playground section allows visitors to interact with the website through three activities.

#### Music Vibe Quiz

A short interactive quiz containing four questions about music preferences.

Each answer contributes to one of three possible results:

- The Energy Seeker
- The Dreamy Listener
- The Sound Explorer

The quiz includes a progress bar, previous-question navigation, a personalized result, and a restart button.

#### Rock, Paper, Scissors

A classic game where the visitor plays against the computer.

The computer randomly selects rock, paper, or scissors.

The game displays both choices, determines the winner, updates the scores, and provides a restart button.

#### Higher or Lower

A card game based on a standard deck of 52 cards.

The visitor must guess whether the next card has a higher or lower value than the current card.

Aces are considered low.

Correct guesses increase the score, while incorrect guesses or ties reset the current streak.

The game also tracks the best score during the current page session.

### 6. Beyond the Rules

The final section explores play beyond traditional games and rules.

It encourages visitors to imagine unusual possibilities, such as playing with time, pausing reality, or transforming everyday experiences into games.

The section ends with a "Play again" button that returns to the homepage.

## Design

The website uses a custom visual theme called Midnight Pink.

The main design elements include:

- Dark purple backgrounds
- Pink and lavender accents
- Rounded cards and buttons
- Gradient typography
- Astronaut illustrations
- Hover effects and subtle transitions

The design aims to create a playful atmosphere while keeping the content readable and organized.

## Responsive Design

The website uses CSS Grid, Flexbox, and media queries to adapt its layout to different screen sizes.

On smaller screens:

- Multi-column sections become single-column layouts
- Navigation links wrap when necessary
- Illustrations are resized
- Interactive elements are adjusted for smaller displays

## Accessibility

The website includes several accessibility features:

- Semantic HTML elements
- Alternative text for the astronaut illustrations
- Keyboard-accessible buttons and navigation
- Visible keyboard focus indicators
- A "Skip to content" link
- ARIA attributes for interactive controls
- Live status messages for quiz and game updates
- Reduced-motion support

## SEO

## How to Run

1. Download or copy the project folder.
2. Make sure all files and the images folder are in the correct locations.
3. Open `index.html` in a modern web browser.

The website works locally and does not require a server, database, or installation process.
